# gw-checkup · 公文格式自查规则

> 零依赖、纯函数的中文公文格式自查工具。Node / 浏览器 / 微信小程序通用。
> 🧪 **在线试用**：https://williamdwz.github.io/gw-checkup/ （粘贴一段公文即出结果，纯浏览器本地运行）
> 项目主页：[gwhub.cn](https://gwhub.cn) ｜ 在线检索：[gw.gwhub.cn](https://gw.gwhub.cn)

输入一段公文正文，返回一个评分和问题清单——每条问题都告诉你**为什么不规范**、**怎么改**，而不只是标个红。

```js
const { check } = require('./gw-checkup.js');

const result = check('关于……的通知\n各部门：\n……\n特此通知。');
// → { score: 85, items: [{ level: 'ok' | 'warn', title: '...', detail: '...' }, ...] }
```

## 为什么做这个

写材料的人最怕的不是不会写，是**发出去之后被挑格式错**：文种用错、标题缺要素、结尾用语不对、主送机关写成"各位领导"。

市面上的检查工具大多要求上传文档、依赖某家办公软件、或者只给一个"不合格"而不说原因。这个库只有 5KB，零依赖，纯函数——**文本只在你的进程里处理，不上传、不联网**。

规则来自真实公文语料（我们在 [gwhub.cn](https://gwhub.cn) 整理了 9 万+ 篇政府公开公文），不是凭感觉编的。

## 用法

### Node

```js
const { check } = require('./gw-checkup.js');
const r = check(text);
console.log(r.score, r.items.filter(i => i.level === 'warn'));
```

### 浏览器

```html
<script src="gw-checkup.js"></script>
<script>
  const r = window.GWCheckup.check(text);
</script>
```

### 微信小程序

```js
const { check } = require('/utils/gw-checkup.js');
```

## 返回结构

```ts
{
  score: number,          // 0-100 综合评分
  items: Array<{
    level: 'ok' | 'warn',
    title: string,        // 检查项名称（如「文种结尾用语」）
    detail: string        // 具体问题与建议改法
  }>
}
```

## 检查哪些项

| 类别 | 检查内容 |
|---|---|
| **文种** | 标题里的文种是否在 12 种法定文种内（通知/报告/请示/批复/意见/方案/总结/纪要/决定/函/公告/通告） |
| **标题结构** | 是否包含「发文机关 + 事由 + 文种」三要素 |
| **主送机关** | 是否存在、是否用了「各位领导」「大家」这类非规范称谓 |
| **结尾用语** | 按文种匹配期望结尾（如请示→「妥否，请批示」，批复→「此复」） |
| **句长** | 单句过长会提示拆句（公文讲究一句一事） |
| **口语词** | 检出「搞定」「弄一下」「差不多」等不适合进入正式文书的表述 |

每条规则都附「为什么」和「怎么改」，示例：

```
⚠ 文种结尾用语
   请示类公文应以「妥否，请批示」或「请予批复」结尾，
   当前结尾为「特此通知」，属于通知类用语。
```

## 设计原则

1. **零依赖、纯函数**——不读写存储、不请求网络，文本只在调用方进程内处理
2. **规则可读**——所有规则集中在文件顶部，改规则不用读框架源码
3. **说人话**——每条问题都给原因和改法，不做"只报错不解释"的黑箱

## 常见问题

**它能替代人工审核吗？**
不能。它查的是**格式惯例**（文种、结构、用语），不判断内容是否得体、事实是否准确、是否涉密。正式发文前仍需人工复核。

**规则会不会误判？**
会。公文写法有地域和系统差异（比如某些系统不用「特此通知」）。所以它给的是 `warn` 而不是 `error`——**提示你复查，不是判定你错**。

**支持 .docx 直接读吗？**
不支持。这个库只处理纯文本。取文本请用你自己的解析方案。
